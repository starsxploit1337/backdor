# 🧠 Tentang Project

**0xStars Shell v2.0** adalah panel kontrol berbasis PHP yang dirancang untuk:

- Simulasi interaksi server
- Pembelajaran keamanan web
- Monitoring environment server
- Eksperimen di lingkungan lab

Project ini dibuat untuk kebutuhan edukasi & testing pribadi.

---

# ⚡ Fitur Utama

## 📂 File Manager
- Navigasi direktori
- Upload & download file
- Melihat permission file

## 🖥 Terminal Interface
- Eksekusi perintah (untuk lab pribadi)
- Inspeksi informasi sistem
- Monitoring proses berjalan

## 📊 Monitoring Server
- CPU Load
- Penggunaan Memory
- Status Disk
- Uptime
- Versi PHP
- Software Server
- IP Address

## 🔐 Sistem Login
- Proteksi berbasis session
- Monitoring aktivitas login
- Pencatatan IP Address

# 🛡 Sistem Bypass

Sistem keamanan seperti:

- LiteSpeed
- Cloudflare
- Apache ModSecurity

dibuat untuk melindungi server.

Project ini TIDAK:
- Menyediakan teknik bypass
- Menonaktifkan firewall
- Melewati proteksi keamanan

Belajar keamanan berarti memahami cara memperkuat sistem, bukan merusaknya.
